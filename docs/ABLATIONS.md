## What this shows

- **Semantic and hybrid retrieval beat keyword-only** on recall (0.98 vs 0.90) and MRR (0.95 vs 0.83); the confidence intervals barely overlap, so the gap is likely real even at this sample size.
- **Hybrid is on par with vector-only** when the embeddings are strong: weighting the vector leg higher (1.0 / 0.5) gives the best hybrid MRR (0.951), and weighting keyword higher hurts (0.924). Hybrid stays the default because it protects exact-identifier queries (codes like `ERR-4471`, `D-604`) if embeddings change.
- **Cross-tenant leakage: 0** retrieved passages from the second client across all configurations.
- **Chunk size (200 / 350 / 600 tokens) made no difference**: every document section is shorter than 200 tokens, so the heading-aware chunker produced the same 68 chunks each time. Chunk-size sensitivity can't be measured on this corpus; it needs longer documents.

Confidence intervals are percentile bootstrap over questions; overlapping intervals mean a difference is not established at this sample size.
